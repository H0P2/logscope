# LogScope

브라우저에서 텍스트 로그를 분석하고 ERROR, WARN, INFO 이벤트를 빠르게 확인할 수 있는 경량 로그 분석 도구입니다.

## 주요 기능

- 로그 직접 입력
- `.txt`, `.log` 파일 불러오기
- 최대 2MB 파일 크기 제한
- ERROR / WARN / WARNING / INFO 탐지
- 로그 레벨별 통계
- 로그 비율 시각화
- 이벤트 필터
- 실시간 검색
- 원본 로그 줄 번호 유지
- 키보드 조작 지원
- Reduced Motion 지원

## 사용 방법

1. 로그 내용을 직접 입력하거나 로그 파일을 선택합니다.
2. `Analyze Log` 버튼을 누릅니다.
3. 분석 통계와 이벤트 목록을 확인합니다.
4. Error, Warning, Info 필터와 검색창으로 원하는 이벤트를 찾습니다.

## 기술

- HTML5
- CSS3
- Vanilla JavaScript
- FileReader API
- Regular Expressions

별도의 서버, 데이터베이스 또는 외부 라이브러리를 사용하지 않습니다.

- 1366 × 768

## 발견하고 수정한 문제

### 1. 실제 로그 줄 번호 불일치

**수정 전**  
빈 줄을 삭제한 뒤 줄 번호를 계산해 실제 로그 파일의 줄 번호와 달랐습니다.

**수정 후**  
원본 줄 배열의 인덱스를 유지해 실제 줄 번호를 표시하도록 수정했습니다.

### 2. 파일 선택 상태 불일치

**수정 전**  
로그 파일을 선택한 뒤 샘플 로그를 불러오면 이전 파일명이 계속 표시되었습니다.

**수정 후**  
샘플 로그를 선택하면 기존 파일 선택 상태도 함께 초기화하도록 수정했습니다.

### 3. 오래된 분석 결과 표시

**수정 전**  
분석 완료 후 로그 내용을 변경해도 이전 분석 결과가 화면에 남아 있었습니다.

**수정 후**  
로그 입력이 변경되면 기존 결과를 초기화하고 재분석이 필요하다는 메시지를 표시하도록 수정했습니다.

## 보안 및 개인정보

- 서버로 로그를 전송하지 않습니다.
- 브라우저 안에서만 파일을 읽고 분석합니다.
- API Key, 비밀번호, 토큰을 사용하지 않습니다.
- 사용자 로그 출력에는 `textContent`를 사용하여 입력 HTML이 실행되지 않도록 처리했습니다.

## 프로젝트 목적

서버와 시스템 로그에서 필요한 정보를 빠르게 확인하는 과정을 웹 인터페이스로 구현하며 문자열 처리, 파일 처리, 데이터 분류와 사용자 인터페이스 설계를 연습하기 위해 제작했습니다.
